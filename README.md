# CommunityPulse 社区舆情雷达

给游戏运营用的评论分析工具。给一个链接（或把评论粘进来），自动抓评论，然后统计高频词、聚类相似诉求、判定情感、看趋势，最后导出一份报告。

数据全部存在你自己的电脑上，不上传任何地方。

## 本次更新

相对上一版的改进：

- 监测清单这次真的会盯了。库里那三条监测的增删改查早就写好，但没有任何接口和调度器去调它，界面上点了没反应。现在补了 8 个接口（列表 / 历史 / 新建 / 跑一次 / 开关 / 删除 / 预警 / 标已读），并起一个后台巡检线程，按每条各自填的间隔（默认 24 小时）到期才跑，每条一个线程，正在跑的直接跳过，不会重复排队。
- 预警中心和界面对上字段了：未读数、按级别过滤、标已读都是接口真返回的结果，不是面板上写死的样例。这条单列，是因为之前踩过「接口通了、页面还是空白」这种看着像完成的坑。
- 界面重排：左栏改成页签分组，顶栏换成品牌色带，KPI 数字按语义着色，分析设置改 3 列网格。顺带修了 ECharts 实例泄漏，来回切页不会再一直攒着不释放。
- 零依赖模式下现在真切得出词。没装 jieba 时的兜底分词，偶数长度切不重叠二元组、奇数长度直接吐单字，而单字又会被当噪声丢掉 —— 一句长评论在没装包的机器上几乎不贡献任何词，「不装 jieba 也能正常跑」这句话在词频和情感统计上原本是空的。改成步长 1 的滑窗二元组，「太肝」「闪退」这类跨切分边界的搭配才切得出来。代价是零依赖下词条数约为原来的两倍，纯 stdlib 的分词质量仍然不如 jieba，装上就好。
- CI 四条腿全红的原因查到底并修完，一共四条：`启动.bat` 和 `停止.bat` 从没入库，而 `test_make_bat` 要求它们在，干净检出必然报文件丢失；两个套件绕过启动流程直接写库，可建表本来是服务启动时做的，干净检出或新装机上还没有 `data/pulse.db`，8 个并发线程全抛 `no such table: tasks`（开发机上测不出来，因为那个库早就存在了）；默认导出的断言拿跑测试这台机器的环境去要求服务端，没装 openpyxl 时服务端正常降级成 CSV 却被判失败；Windows runner 上 python 的标准输出走系统 ANSI 代码页，tools/ 下 20 个脚本只有 8 个自己包了 UTF-8，剩下 12 个整片死在 UnicodeEncodeError。现在「零依赖」和「装齐」两档在干净检出里各 18 套全绿，并起真服务把端点全量巡一遍。
- 两个写好的套件收进统一入口：`test_alert_center`（31 项）和 `test_watchlist`（61 项）一直在 tools/ 里，但没登记进 run_tests 的清单，等于白写。现在收进来并标成慢套件（要起真服务），`--quick` 会跳过它们。
- 加了 `tools/route_snapshot.py`：把全部路由的真实响应存成 JSON，重构前后各跑一次做 diff。它抓的是「路由还能通、但行为悄悄变了」这类回归 —— 只看状态码是 200 看不出来。
- 加了 `tools/export_site.py`：只读 `data/pulse.db` 导一次分析结果给站点用。不写库、不联网、不碰 Cookie 和 API Key，评论者用户名一律去掉。

## 启动

双击 `启动.bat`，浏览器会自动打开 http://127.0.0.1:8766 。

- 那个黑色窗口不要关，关掉就等于停止服务。
- 要停止就双击 `停止.bat`。
- 换端口：`启动.bat 9000`。

免安装版（压缩包里有 `runtime` 文件夹的那种）解压后同样是双击 `启动.bat`，不用装 Python，也不用联网装依赖。

## 怎么用

### 第一步 采集

链接框里粘贴社区链接，每行一个，可以一次提交多个视频 / 帖子，评论会合并进同一个任务一起分析。填好目标条数和排序方式后，先点「先试抓」看看实际能抓到多少，再点「开始采集」。

抖音和小红书服务端抓不了，走「手动导入」（见下文）。

### 第二步 分析

采完会自动分析。也可以选中任务后点「分析选中任务」。

### 第三步 导出

Excel（多页明细）、CSV、HTML 报告（单文件，可直接发给别人看）。

### 其他常用操作

- 关键词发现（左栏）：不知道该盯哪些帖子时用。输入游戏名 / 版本名搜出相关帖子，勾选后一键批量采集。
- 重采（任务列表）：对同一个来源再抓一次，只把新增评论入库（按评论 ID 去重），适合长期跟踪。
- 仅分析热度前 N 条（分析参数）：采 5000 条但只分析高赞前 500 条，用来滤掉水评。填 0 表示全部。
- Cookie 设置（左栏底部）：填了能拿到更完整的评论，只存在本机 `data\settings.json`。

### 条数和排序怎么理解

- 按热度取前 N 条（推荐）：先抓热评，不够再用时间序补，最后统一按点赞从高到低取前 N 条。
- 按时间取最新 N 条：只走时间序。
- 热度 + 最新合并：两路都抓，凑够后按热度取前 N 条。

目标条数填多少就尽量抓多少，一直翻页到抓满或抓干为止。没抓满会在界面上写明原因，不会默默给你一个说不清的数字。

## 能看到什么

- 高频词条：TF-IDF 加权词频 + 条形图，点词条可看包含它的原句。
- 新词 / 黑话：按凝固度自动识别新梗，比如「吃保底」「沉船」「长草」。
- 相似句聚类：把用词不同但诉求相同的反馈归成一族，给出代表句和族内样本。
- 吐槽点归类：性能、商业化、玩法平衡、剧情美术、内容更新、新手引导、运营客服、社交联机、UI 操作。
- 情感分布：正面 / 中立 / 负面占比，以及最负面和最正面的原声。
- 声量趋势：按天看声量和负面率变化，定位版本更新后的口碑波动。
- 重点原句：高赞、高频诉求、强烈负面三类，可以直接引用给研发。

可调参数：相似句阈值（默认 0.45，越低合并越多）、Top N、额外停用词。

## 各平台支持情况

- B站：匿名可用，能大量翻页，含楼中楼。
- Steam：稳定，可跨语言。
- Reddit：稳定。
- YouTube：需要在设置里填 API Key。
- 微博：免登录约 15 条（游客上限），填 Cookie 可突破。
- 贴吧 / NGA：页面解析，可能随改版失效。
- TapTap：受限，填 Cookie 能提升成功率。
- 抖音 / 小红书：用浏览器采集助手（见下）。
- 其他网页：通用评论区抽取作为兜底。

## 抖音 / 小红书怎么采

这两个平台有签名风控，服务端直连不可靠。工具改成用你自己的浏览器和登录态采集：

1. 点左侧「手动导入」里的 复制浏览器采集脚本。
2. 在 Chrome / Edge 打开目标视频或笔记页（建议先登录）。
3. `F12` → `Console` → 粘贴脚本 → 回车 → 输入目标条数。
4. 脚本自动滚动加载评论，跑完自动下载一个 JSON。
5. 把这个 JSON 拖进「手动导入」框。

它不算签名、不改请求，只是把你浏览器本来就会收到的评论数据拦下来汇总。

## 注意事项

### 采集相关

- 平台随时可能改版，解析类采集器失效是正常现象。手动导入永远可用，是这些平台的兜底方案。
- B站触发风控（code -412）说明请求太快：降低目标条数、稍后重试，或填 Cookie。
- 未登录时看不到全部楼中楼，界面会提示「该视频共 N 条，本次取到 M 条」。
- 微博对游客有硬限制（约 15 条），不填 Cookie 也能用，只是量少。
- 请遵守各平台的使用条款，控制采集频率，不要大批量爬取。

### 使用相关

- Cookie 只写在本机 `data\settings.json`，不会跟着工具一起发给别人。
- 换游戏项目时，改 `app/analysis/dict/userdict.txt`（领域词典）和 `app/analysis/lexicon.py`（诉求概念）里的词表，重启服务生效。
- 免安装版目前只支持 Windows 64 位；macOS / Linux 用 `启动.sh`，需要系统装有 Python 3.9 以上。
- 升级到带复合索引的版本后，老库不用重装。服务每次启动都会检查并补建缺的索引，第一次启动可能会多花一两秒（库大时更明显），之后就正常了。库文件在 `data\pulse.db`，10 万条评论的体量下索引约占 1.7MB。

### 打不开怎么办

- 双击后一堆「不是内部或外部命令」：bat 被存成了错误的换行或编码，重新生成 `python tools\make_bat.py`。
- 提示端口被占用，跳到别的端口：属正常行为，用窗口里显示的新地址；或先跑 `停止.bat`。
- 浏览器白屏 / 连不上：看黑窗口里的报错，或换个端口重试。

`启动.bat` / `停止.bat` 由 `tools\make_bat.py` 生成，不要直接用记事本改（记事本容易把它存成 LF 换行或 UTF-8，bat 就失效了）。要改内容请改 `make_bat.py` 后重新生成。

## 目录结构

```
启动.bat              双击启动
停止.bat              停止服务
app/
  ├─ server.py        Web 服务
  ├─ core/            配置 / SQLite / HTTP 客户端
  ├─ collectors/      各平台采集器 + 导入解析
  ├─ analysis/        分词 / 词频 / 聚类 / 情感 / 主题
  └─ export/          Excel / CSV / HTML 报告
web/                  前端页面（含本地 ECharts，离线可用）
data/                 数据库 pulse.db、导出文件、设置
tools/                打包与冒烟测试脚本
```

改完代码跑一下：`venv\Scripts\python.exe tools\smoke_test.py`

## 分发给别人

```bat
python tools\make_dist.py --portable
```

产出在 `dist\CommunityPulse-日期.zip`，解压双击 `启动.bat` 即可，对方不用装 Python 也不用联网。

打包时会排除 `data\`（你的采集数据和登录态）、`venv\`（绑死本机路径，搬走会失效）、`logs\`，所以发出去的东西里不含任何你的登录信息。

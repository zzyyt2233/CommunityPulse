# CommunityPulse · 社区舆情雷达

给游戏运营用的评论区舆情工具：给一个链接（或粘贴评论），自动抓评论 → 统计高频词条 →
聚类相似诉求 → 判定情感 → 归类吐槽点 → 看趋势 → 导出报告。

全部代码、数据、依赖产物都在**项目自己的目录**里，装在哪都行，不往系统盘写东西。

---

## 一、启动

双击 **`启动.bat`**，浏览器会自动打开 `http://127.0.0.1:8766`。
黑色窗口不能关，关了服务就停。手动停止用 **`停止.bat`**。换端口：`启动.bat 9000`。

### 打不开怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后窗口一堆「不是内部或外部命令」 | bat 被存成了 LF 换行或 UTF-8 编码 | 重新生成：`python tools\make_bat.py`（它会强制 CRLF + GBK） |
| 提示端口已被占用，跳到了别的端口 | 8766 上已经有别的服务（含本工具的旧实例） | 属正常行为，用窗口里显示的新地址；或先跑 `停止.bat` 再启动 |
| 浏览器白屏 / 连不上 | 服务没起来或被安全软件拦了 | 看黑窗口里的报错；换端口重试 |
| 昨天能用今天打不开 | 服务进程随上次会话一起退出了 | 重新双击 `启动.bat` |

> 说明：`启动.bat` / `停止.bat` 由 `tools\make_bat.py` 生成，**不要直接用记事本改**——
> 记事本很容易把它存回 LF 换行或 UTF-8，导致 bat 失效。改内容请改 `make_bat.py` 后重新生成。

## 二、三步出结果

1. **采集**：粘贴社区链接 → 填**目标条数**（想抓多少就填多少）→ 选**排序方式** →
   先点「先试抓」看实际能抓到多少 → 点「开始采集」。
   抓不到的平台（抖音 / 小红书）用左侧「手动导入」粘贴或传 CSV / JSON。
2. **分析**：任务完成后会自动分析；也可选中任务点「分析选中任务」。
3. **导出**：Excel（多页明细）/ CSV / HTML 报告（单文件，可直接发给研发和老板）。

### 批量采集：一次盯多个来源

链接框**每行填一个**，一次可提交多个视频 / 帖子，全部评论合并进同一个任务一起分析。
适合「同一个版本，把 B站官方号 + 几个大 UP 主 + 官微的反馈一起看」。

### 关键词发现：不知道该盯哪些帖子时用

左栏「关键词发现」输入游戏名 / 版本名（如「原神 卡顿」）→ 搜出相关视频 →
勾选 → 一键批量采集。B站搜索匿名可用，会显示播放量、评论数、弹幕数，方便挑重点。
搜索是 AND 语义，多词太严格时工具会自动退回主关键词再搜一次。

### 重新采集：长期跟踪同一个帖子

任务列表里点「**重采**」，按同样的来源再抓一次，**只把新增评论入库**（按评论 ID 去重），
消息里会写明「新增 N 条（累计 M 条）」。隔几天重采一次就能看出舆情增量。

### 条数与排序怎么理解

| 排序方式 | 行为 |
|---|---|
| **按热度排序，取前 N 条**（推荐） | 先抓热评，不够再用时间序补量，最后统一按点赞从高到低取前 N 条 |
| **按时间排序，取最新 N 条** | 只走时间序，取最新 N 条 |
| **热度 + 最新合并** | 与「按热度」相同：两路都抓，凑够 N 条后按热度取前 N |

「目标条数」是你说了算：工具会一直翻页直到抓满 N 条或抓干为止。
**没抓满会在界面上写明原因**，不会默默给你一个说不清的数字。

另外分析时还能单独设「**仅分析热度前 N 条**」（0 = 全部）：
采集 5000 条、只分析高赞前 500 条，适合排除水评噪声。
来源没有点赞数据时（贴吧 / NGA / 手动导入）该设置会自动忽略并提示。

### 抓不满的常见原因与对策

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 该视频共 N 条，本次取到 M 条 | 未登录看不到全部楼中楼 | 想拿更全就在「设置」填 `bilibili_cookie`（F12 复制 Cookie，含 SESSDATA） |
| 已到评论末尾 | 该来源评论全部取完 | 正常，说明确实只有这么多可抓的 |
| B站触发风控 code -412 | 请求太快 | 降低目标条数、稍后重试、填 Cookie |
| 微博访客身份只能看到约 15 条 | 微博对游客有硬限制 | 设置里填 `weibo_cookie`（登录微博后 F12 复制 Cookie 请求头）；不填也能用，只是只有 15 条 |
| TapTap 接口带签名校验 | 需登录态 | 设置里填 `taptap_cookie`，或手动导入 |
| 评论总量不足目标条数 | 这个帖子本身就这么些评论 | 换帖子，或把目标条数调低 |

界面上「目标 / 实得」旁会同时显示**该来源评论总量**和本次覆盖百分比，
方便判断"是没抓到，还是本来就这么多"。



#三、能看到什么

| 模块 | 说明 |
|---|---|
| 高频词条 | TF-IDF 加权词频 + 条形图，点词条可看包含它的原句 |
| 新词 / 黑话 | 按凝固度自动识别新梗，如「吃保底」「沉船」「长草」 |
| 相似句聚类 | 把用词不同但诉求相同的反馈归成一族，给出代表句 + 族内样本 |
| 吐槽点归类 | 性能/商业化/玩法平衡/剧情美术/内容更新/新手引导/运营客服/社交联机/UI操作 |
| 情感分布 | 正面 / 中立 / 负面占比 + 最负面与最正面原声 |
| 声量趋势 | 按天看声量与负面率变化，定位版本更新后的口碑波动 |
| 重点原句 | 高赞、高频诉求、强烈负面三类，直接可引用给研发 |

可调参数：相似句阈值（默认 0.45，越低越合并）、Top N、额外停用词。

四、各平台接入情况

| 平台 | 方式 | 状态 |
|---|---|---|
|B站* | WBI 签名接口（`/x/v2/reply/wbi/main`），失败降级老接口 | ✅ **匿名即可大量翻页**，含楼中楼 |
| **Steam** | 商店评测官方接口 | ✅ 稳定，可跨语言 |
| **Reddit** | 帖子 `.json` | ✅ 稳定 |
| **YouTube** | 官方 API（需在设置填 Key） | ✅ 需 API Key |
| **微博** | PC 端 `buildComments` + 官方访客身份 | ⚠️ 免登录约 15 条（游客硬上限），填 `weibo_cookie` 可突破 |
| **贴吧 / NGA** | 页面结构解析 | ⚠️ 可能随改版失效，失败请用手动导入 |
| **TapTap** | 评论接口（带签名） | ⚠️ 受限，可在设置填 Cookie 提升成功率 |
| **抖音 / 小红书** | 浏览器采集助手（见第五节） | 🔧 服务端不直连，用你自己浏览器导出 JSON |
| **任意网页** | 通用评论区抽取 | 兜底，抓不到结构化数据时切正文候选句 |

能用它做什么

  • 高频词条与新词黑话：TF-IDF 加权词频，自动识别「吃保底」「沉船」这类新梗。
  • 相似句聚类：用词不同但诉求相同的反馈归成一族，给代表句和族内样本。
  • 吐槽点归类：性能、商业化、玩法平衡、剧情美术、内容更新等九类。
  • 声量趋势与重点原句：高赞、高频诉求、强烈负面，可直接引用给研发。
  • 导出 Excel / CSV / 单文件 HTML 报告，报告可直接发给别人看。

数据放在哪里 本机，不出门

  • 评论与分析结果存在 data\pulse.db，导出的文件在 data\ 下。
  • Cookie 与 API Key 用 Windows DPAPI 加密后写进 data\settings.json，拷到别的机器解不开。
  • 打包分发时默认排除 data\，发出去的压缩包里不含你的登录信息。
  • 服务日志在 logs\app.log，超过 5MB 自动归档保留 3 份。
